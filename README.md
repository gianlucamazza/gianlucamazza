  LLM-driven state machines. Gates decide, checkpoints resume, and the experiment
  pages publish their negative results.

  priority queue takes requests from many channels into traced LLM workflows.
- [emotional-memory](https://github.com/gianlucamazza/emotional-memory): a memory
  layer for LLMs with reproducible benchmarks
  ([DOI 10.5281/zenodo.19972258](https://doi.org/10.5281/zenodo.19972258)); results
  outside the regime where it helps are reported.
- [openfatture](https://github.com/gianlucamazza/openfatture): open-source FatturaPA
  e-invoicing for Italian freelancers, CLI-first.
